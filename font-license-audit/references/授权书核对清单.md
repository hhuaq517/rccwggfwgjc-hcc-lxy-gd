# 授权书核对清单

拿到字体授权书（或采购合同附件）后，逐条对，缺一条就不能判"合规"。

## 一、权利人是否对得上

- [ ] 授权方是**字库厂商本体**或其**正式授权代理**（注意代理的转授权是否被允许）
- [ ] 授权书上的字体名，与物料里实际使用的字体名**能对应上**
      （厂商常按"字库名+字重"命名，如"汉仪旗黑 65S"，只买了 45S 却用了 65S 是超范围）
- [ ] 矢量/静态两版是否都覆盖（有的授权只含静态字库，不含可变字体）

## 二、用途（媒体）—— 最容易踩的一条

- [ ] 授权列明的媒体类型：印刷 / 网络 / 视频 / 户外 / 商标 / 影视
- [ ] **本批物料属于哪一类**：公众号推图 = 网络信息传播；短视频 = 视频
- [ ] 只买"印刷"授权的字体，**不能**直接用于推图
- [ ] 是否含"信息网络传播权"，还是仅"复制权/发行权"

## 三、主体

- [ ] 被授权方是**集团**还是**某家子公司**
- [ ] 是否覆盖**分子公司 / 加盟商 / 经销商**
- [ ] **外包设计公司**做的物料：外包方使用字库需要它自己的授权，
      本单位的授权通常不覆盖外包方 —— 这是高频超范围场景
- [ ] 员工个人电脑上安装使用是否被允许（台数/席位）

## 四、期限与数量

- [ ] 生效日 / 到期日；到期后继续使用即侵权（需续约或替换物料）
- [ ] 授权台数 / 并发数 / 安装设备数是否够用
- [ ] 是**一次性买断**还是**年度订阅**（订阅类的历史物料是否仍可用，看条款）

## 五、地域与其他

- [ ] 地域范围（中国大陆 / 全球）
- [ ] 是否允许修改字形（有些授权禁止变形、禁止做 LOGO 字体）
- [ ] 是否允许用于**商标注册**（这个通常要单独买，且贵）
- [ ] 是否允许嵌入到 PDF / 电子资料中分发

## 六、存档要求

- [ ] 授权书/合同扫描件、发票、字体文件、采购记录**一起归档**
- [ ] 记录每份物料的**发布时间与所用字体**，便于日后回溯
- [ ] 建立字体使用台账：字体名 → 用途 → 授权依据 → 到期日

---

## 常见误区

| 误区 | 实际 |
|---|---|
| "公司买过这款字体，随便用" | 授权按媒体/主体/期限限制，超出即侵权 |
| "设计公司做的图，字体是他们的责任" | 侵权责任最终落在**发布方**（你们）身上 |
| "改了字形就看不出是原字体" | 变形使用反而可能同时侵犯修改权与保护作品完整权 |
| "系统自带的字体都能商用" | 微软雅黑、宋体等的商用授权另有约定，并非"装了就随便用" |
| "免费下载的字体就是免费商用" | 免费下载 ≠ 免费商用，需看具体授权协议（如仅限个人非商业） |
| "先用了，被投诉再补买" | 历史物料的赔偿风险已发生，且补买通常不溯及既往 |
