# 违规词替代对照表

> 用途：每判定一处违规表述，**必须**从本表（或按同样原则临场拟）给出 2–3 个可直接抄进图里的替代写法。
> 配套依据：`references/compliance-rules.md`

## 选替代词的三条原则

1. **不产生新风险**——不能一边删掉"最好"，一边写上"100% 覆盖"。
2. **不虚构事实**——替代词只能删减或限定原意，不能凭空加数据、加承诺、加背书。
3. **能直接抄进图**——长度贴近原文，推图标题控制在 4–8 字，口语顺。

## 一、绝对化 / 极限词

| 违规表述 | 替代写法（2–3 个） | 说明 |
|---|---|---|
| 最好 / 最全 / 最先进 / 最新 | 更贴合考情 / 覆盖全面 / 系统梳理 | "最"字一律去掉，改成描述内容本身 |
| 最长（线班型） | 课时更充足 / 课时量更大 / 长线班型 | 描述客观课时，不做横向比较 |
| 第一 / No.1 / Top1 | 领先 / 资深 / 长期专注 / 有口碑 | 不得做排名断言 |
| 一流 / 顶级 / 极品 / 超级 | 优质 / 精品 / 高阶 / 精品小班 | — |
| 唯一 | 专门开设 / 专业设置 | 删掉"唯一" |
| 首家 / 首创 | 较早开设 / 先行探索 | — |
| 100%（通过 / 覆盖） | 高比例；有数据时写实际比例并标注来源 | 无来源就删 |
| 国家级 / 世界级 / 全球范围 | 规范化 / 体系化 / 符合国家考试大纲 | 不得借用"国家级"背书 |
| 无限（无限学） | 长期有效（注明截止日期）/ 不限次数（注明次数上限）/ 协议期内可重复学习 | "无限"本身禁用，且必须写明期限 |
| 精准（精准预测 / 精准提分） | 针对性强 / 贴合考纲 / 逐项突破 | — |
| 权威 / 独家（解读） | 学习 / 研读 / 理解 / 分享 / 考情梳理 | 见第七节 |

## 三、贩卖焦虑 / 制造紧张

| 违规表述 | 替代写法（2–3 个） | 说明 |

## 四、价格与优惠

| 违规表述 | 替代写法（2–3 个） | 说明 |
|---|---|---|
| 加量不加价 | 课时增加，价格不变（并列写清前后课时与价格） | 必须给出可核对的基准 |
| 预估到手价 / 参考价 / 直降价 | 现价 XXX | 一律不用这些形式 |
| 原价 XXX（7 日内无成交） | 直接标现价；确有原价则补"原价 XXX（成交期间：X 月 X 日–X 月 X 日）" | 原价须 7 日内有成交记录 |
| 免费 / 零元 / 原价（公开课场景） | 公益 | 公开课 / 峰会讲销分开，统一用"公益" |
| 赠品"豪礼相送" | 赠《XXX》讲义 1 本，X 月 X 日前报名领取 | 须写品种、规格、数量、期限、领取方法 |
| 限量 / 仅限 XX 名（未写数） | 限量 XX 名 | 数量必须写明 |
| 优惠 / 折扣（未写时间） | 优惠时间：X 月 X 日 – X 月 X 日 | 活动时间必须写明 |
| 仅需 XXX 元 / 只要 XXX 元 | 现价 XXX 元 / 课程价格 XXX 元 | "仅需"是比较性表述；与"原价"并用时构成价格对比链，两价都须真实可溯 |
| 住宿费一口价 XXX 元 / 一口价 | 住宿费 XXX 元/人（标准双人间）/ 住宿自愿选择，费用 XXX 元 | "一口价"本身是价格承诺，须写明**住宿标准 + 是否含餐 + 是否必选**，信息不全反而易起争议 |
| 赠品（未写领取方式与期限） | 报名后于 XX APP 领取 / 开课前由班主任发放 / X 月 X 日前报名方可领取 | 赠品除品种、数量外，**领取方法与期限**同样必须明示 |
| 价格 XXXX 起（未写明对应班型 / 不存在更高的价位） | XXXX 元起（基础班型）/ XXXX 元起（走读班，高阶班 XXXX 元）/ 课程价格 XXXX 元 | **"起"是起步价，标示的是最低价——即暗示往上还有更高的价位。方向别搞反：它不暗示有更低价。** 合规要件两条：① 标明该价对应的具体班型；② 确实存在高于该价的价位。若该价已是最高价或唯一价，"起"字无对应事实，属误导性价格表示 |
| 可叠加 XXX 优惠（缺单位 / 缺活动时间） | 可叠加 XXX 元优惠（活动时间：X 月 X 日 – X 月 X 日） | 优惠须写齐三样：**金额单位、触发条件、活动时间**。触发条件写清楚是优点（优于"最高立减 XXX"），别在单位和时间上丢分 |
| 节日限定款 / 限定发售（未写限定范围） | 节日特惠款 / 节庆在售款（限 X 月 X 日前报名） | "限定"须说明限量份数或限时区间，否则"限定"二字无对应事实 |

## 八、无法替代，只能删除或补限定

以下三类**没有安全替代词**，只能删掉或改成可核实的事实陈述：

1. **"押""密""秘"及谐音**（押题、密卷、密训、秘籍、揭秘）——一律禁用，不做替换
2. **无来源、无截止时间、无范围的数据宣称**——补齐三要素，或删除
3. **无成交记录支撑的"原价"**——删除原价，只标现价

---

## 九、给替代词时的硬要求

- 每处违规给 **2–3 个**候选，多了等于没给
- 长度贴近原文，推图标题控制在 4–8 字
- 用引号包裹，多个候选之间用 ` / ` 分隔
- 无法替换的，明确写「建议删除」或「需补 XXX」，**不要硬凑**
- 表里没有的按同原则临场拟，并把新词补回本表
